# Cedar 调度法草案

Cedar 是为测试证据不足而创建的虚构算法名。这是一份概念草案，不是可执行设计文档；保留不完整内容是为了检查系统能否识别资料缺口，而不是用常见算法知识自行补全。

## 定义
Cedar 调度法把任务按资源需求分桶，然后选择候选任务安排执行。草案的目标是减少资源冲突，概念上区分资源紧张和资源充足的情况。任务桶表示资源需求类别，不等同于固定优先级，也没有给出可直接计算的评分函数。

## 已知边界
草案只讨论单机任务队列，不涉及多机一致性或跨区域部署。资源信息来自任务提交时的描述；这些描述是否准确以及运行中如何更新仍未验证。本文没有完成正确性证明，不能宣称算法已经解决全部调度问题。

## 缺失内容
草案未给出分桶阈值、评分权重、完整伪代码、时间复杂度或收敛证明。也没有说明具体的失败重试规则。询问这些细节时，当前知识库无法支持确定答案，不能把其他调度算法的参数移植过来当作 Cedar 的实现。

## 后续记录
后续设计需要补充任务样本、可复现环境、输入输出契约和实验结果。现阶段可以讨论已记录的定义与边界，但不能把待办项当成已经实现的能力。知识库也没有 Cedar 的作者联系方式、正式发布时间或商业收益资料。
