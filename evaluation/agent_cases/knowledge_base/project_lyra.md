# Lyra 项目记录

Lyra 是固定测试知识库中的另一个虚构项目。它用于与 Orion 比较技术选择和部署要求，所有信息都限定在这里描述的演示版本，不应推广为整个组织的产品路线。

## 发布
Lyra 的演示发布日期为 2026-04-02，负责人代号为 L09。此日期表示内部演示交付，不是商业合同生效日。负责人代号不提供真实姓名、电话或私人通信地址，文档也未列出任何客户身份信息。

## 技术
Lyra 使用 Python 服务和 SQLite 元数据存储，当前检索仅使用 BM25，不使用 FAISS。这个选择用于小型文本集合的演示，不构成关于向量检索普遍无效的结论。与 Orion 比较时应分别说明两个项目采用的组件。

## 版本约束
Lyra v1.2 的验证组合为 Python 3.12 与 SQLite 3。该约束属于 Lyra，不能直接套用到 Orion。系统升级前需要检查依赖和数据迁移行为，保留测试记录，并为失败的变更准备回退方案。

## 功能限制
Lyra 当前只接收 TXT 和 Markdown 文本，不接收 PDF。部署端口和资源下限记录在 deployment_notes.md。本文没有给出生产延迟保证、用户增长率、商业定价或服务等级协议，不能根据小型演示推算这些指标。
