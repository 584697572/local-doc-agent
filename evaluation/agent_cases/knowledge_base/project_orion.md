# Orion 项目记录

Orion 是专门为内部诊断构造的虚构项目，下面的代号和日期均为固定测试事实。它与 Lyra 共享文档格式，便于检查系统是否混淆相似名称与版本信息。

## 发布
Orion 的演示发布日期为 2026-03-18，负责人代号为 O17。这里的代号仅用于记录职责，不对应公开姓名。发布记录描述功能进入演示阶段，不表示产品已经商业化，也不包含客户规模与收入预测。

## 技术
Orion 使用 Python 编写服务，检索采用 BM25 和 FAISS，元数据存储使用 PostgreSQL。FAISS 保存向量索引，PostgreSQL 保存文档记录。该技术选择说明组件职责，不能据此确定操作系统、硬件品牌或线上部署位置。

## 版本约束
Orion v2.4 的验证组合为 Python 3.11 与 PostgreSQL 15。Python 3.12 尚未验证，不能仅凭版本较新就认为兼容。变更运行环境前需要重新执行兼容性测试，验证结果应单独记录，不沿用旧组合的结论。

## 功能限制
Orion 当前不支持扫描版 PDF 的 OCR，需要预先提供可提取文本的文档。部署端口与资源要求另见 deployment_notes.md。本记录未公布财务数据、成员联系方式、服务可用性承诺或未来年份的收入。
